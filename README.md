# Сайт Управляющего совета

Первый прототип официального сайта Управляющего совета образовательной организации.

## Что реализовано

- адаптивная главная страница;
- понятные заглушки для отсутствующих фотографий, документов, видео и фактических данных;
- разделы состава, решений, проектов, документов, видеовизитки и новостей;
- интерактивный комплектатор всех 30 конкурсных критериев;
- мобильное меню и переключатель повышенной контрастности.

## Запуск

```sh
pnpm install
pnpm dev
```

Сборка:

```sh
pnpm build
```

Готовые статические файлы будут сохранены в `dist`.
